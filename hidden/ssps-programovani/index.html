Kompilátory vs. Interprety

Jak fungují programovací jazyky?

Počítač rozumí pouze strojovému kódu (binární kód – jedničky a nuly).

My ale píšeme programy v programovacích jazycích (Python, C++, Java...), které jsou pro člověka čitelnější.

Otázka pro žáky: Jak tedy počítač spustí náš program napsaný v Pythonu?

Odpověď: Musíme ho přeložit nebo interpretovat!

Kompilátor

Co je to kompilátor?

Kompilátor = program, který přeloží celý zdrojový kód najednou do strojového kódu.

Proces kompilace:

Zdrojový kód (např. C++) → Kompilátor → Spustitelný soubor (.exe)

Příklady kompilovaných jazyků:

  • C, C++
  • Rust
  • Go
Pro žáky: Představte si to jako překlad celé knihy najednou – dostanete ji celou přeloženou a pak ji můžete číst.

Interpret

Co je to interpret?

Interpret = program, který čte a vykonává kód řádek po řádku, bez předchozího překladu.

Proces interpretace:

Zdrojový kód (např. Python) → Interpret → Přímé vykonání

Příklady interpretovaných jazyků:

  • Python
  • JavaScript
  • Ruby
Pro žáky: Jako kdyby vám někdo překládal knihu nahlas, průběžně, stránku po stránce.

Porovnání

Kompilátory vs. Interprety

Kompilátor Interpret
Rychlost běhu ✓ Rychlejší ✗ Pomalejší
Vývoj a testování ✗ Pomalejší (musí se kompilovat) ✓ Rychlejší (okamžitá zpětná vazba)
Ladění chyb ✗ Složitější ✓ Jednodušší
Přenositelnost ✗ Musí se překompilovat pro každý systém ✓ Stejný kód funguje všude

První program v Pythonu

Hello World!

Tradičně první program v jakémkoliv jazyce jen vypíše text "Hello World".

print("Hello World!")

Praktický úkol:

  1. Zapněte počítače
  2. Otevřete Python (IDLE nebo editor dle vybavení)
  3. Napište: print("Hello World!")
  4. Spusťte program!
Tip: Zkuste změnit text mezi uvozovkami na cokoliv jiného!

Funkce print()

Co dělá print()?

print() je funkce, která vypíše text na obrazovku.

Příklady:

print("Ahoj!")
print("Mám rád programování")
print("Python je snadný")
Důležité: Text musí být v uvozovkách ("..." nebo '...')

Experimentujte:

  • Co se stane, když zapomenete uvozovky?
  • Můžete vypsat více řádků?
  • Zkuste vypsat čísla: print(42)

Proměnné

Ukládání dat do paměti

Proměnná = pojmenované místo v paměti, kam můžeme uložit hodnotu.

jmeno = "Petr"
vek = 15
print(jmeno)
print(vek)

Pravidla pro pojmenování proměnných:

  • Může obsahovat písmena, čísla a podtržítko (_)
  • Nesmí začínat číslem
  • Je citlivé na velikost písmen (vek ≠ Vek)
  • Nepoužívat mezery
Dobrá praxe: Používejte výstižné názvy! (vek je lepší než x)

Datové typy v Pythonu

Základní typy dat

1. Čísla (int, float)

cislo = 42     # celé číslo (int)
pi = 3.14     # desetinné číslo (float)

2. Textové řetězce (str)

jmeno = "Anna"
zprava = 'Ahoj světe!'

Operace s daty:

vysledek = 5 + 3     # sčítání
pozdrav = "Ahoj " + "světe"     # spojování textu

Vyzkoušejte si:

Vytvořte proměnné s vaším jménem a věkem a vypište je pomocí print()!

Co je to algoritmus?

Postup řešení problému

Algoritmus = přesný postup (návod), jak vyřešit daný problém.

Vlastnosti algoritmu:

  • Konečnost – musí skončit v konečném čase
  • Jednoznačnost – každý krok musí být jasně definován
  • Vstup – má nějaká vstupní data (nebo žádná)
  • Výstup – produkuje výsledek
  • Efektivnost – měl by být co nejrychlejší
Každodenní příklad: Recept na vaření je algoritmus!
  1. Vezměte 2 vejce
  2. Rozklepněte je do mísy
  3. Rozšlehejte
  4. ...

Funkce input()

Vstup od uživatele

input() = funkce, která umožňuje uživateli zadat data do programu.

jmeno = input("Jak se jmenujes? ")
print("Ahoj, " + jmeno + "!")
Důležité: input() vždy vrací text (string)!

Převod na číslo:

vek = input("Kolik je ti let? ")
vek = int(vek)     # převod na celé číslo
print("Za rok ti bude: " + str(vek + 1))

int() = převede text na celé číslo
str() = převede číslo na text

Program: Sčítání dvou čísel

Úkol:

Napište program, který:

  1. Zeptá se uživatele na první číslo
  2. Zeptá se na druhé číslo
  3. Sečte je a vypíše výsledek

Řešení:

cislo1 = input("Zadej první číslo: ")
cislo2 = input("Zadej druhé číslo: ")

cislo1 = int(cislo1)
cislo2 = int(cislo2)

soucet = cislo1 + cislo2
print("Součet je: " + str(soucet))
Pozor! Zapomeňte-li převést na int(), Python spojí texty místo sčítání!

Podmíněné skoky

Příkaz if

Podmínky umožňují programu rozhodovat se podle situace.

vek = int(input("Kolik je ti let? "))

if vek >= 18:
    print("Jsi plnoletý!")
else:
    print("Nejsi ještě plnoletý.")

Důležité:

  • Odsazení (indent) je v Pythonu povinné!
  • Použijte 4 mezery nebo Tab
  • : na konci if a else

Porovnávací operátory:

  • == – rovná se
  • != – nerovná se
  • < – menší než
  • > – větší než
  • <= – menší nebo rovno
  • >= – větší nebo rovno

Program: Verifikace věku

Úkol:

Napište program, který:

  1. Zeptá se uživatele na věk
  2. Pokud je věk ≥ 18, vypíše "Můžeš řídit auto"
  3. Pokud je věk < 18, vypíše "Ještě nemůžeš řídit auto"
  4. BONUS: Přidejte kategorii pro věk < 15 (ještě ani na moped)

Řešení s elif (else if):

vek = int(input("Kolik je ti let? "))

if vek >= 18:
    print("Můžeš řídit auto")
elif vek >= 15:
    print("Můžeš řídit moped")
else:
    print("Ještě nemůžeš řídit")

Seznamy (Lists)

Ukládání více hodnot

Seznam = datová struktura pro uložení více hodnot pod jedním názvem.

znamky = [1, 2, 1, 3, 2]
jmena = ["Anna", "Petr", "Jana"]
mix = [1, "ahoj", 3.14, True]     # může obsahovat různé typy

Přístup k prvkům:

znamky = [1, 2, 1, 3, 2]
print(znamky[0])     # vypíše: 1 (první prvek má index 0!)
print(znamky[2])     # vypíše: 1
print(znamky[-1])     # vypíše: 2 (poslední prvek)
Důležité: V Pythonu (a většině jazyků) se indexuje od 0!

Užitečné funkce:

  • len(seznam) – délka seznamu
  • seznam.append(hodnota) – přidání prvku na konec
  • max(seznam) – největší hodnota
  • min(seznam) – nejmenší hodnota

For cyklus

Procházení seznamů

For cyklus = opakování příkazů pro každý prvek seznamu.

znamky = [1, 2, 1, 3, 2]

for znamka in znamky:
    print(znamka)

Tento program vypíše každou známku na samostatný řádek.

Další příklady:

jmena = ["Anna", "Petr", "Jana"]

for jmeno in jmena:
    print("Ahoj, " + jmeno + "!")
Tip: Název proměnné v cyklu (znamka, jmeno) si můžete zvolit sami!

Finální program: Analýza známek

Úkol:

Napište program, který:

  1. Má seznam známek: [1, 2, 3, 1, 2, 4, 1, 3]
  2. Najde a vypíše nejlepší známku (nejmenší číslo)
  3. Najde a vypíše nejhorší známku (největší číslo)
  4. BONUS: Spočítá průměr

Řešení:

znamky = [1, 2, 3, 1, 2, 4, 1, 3]

nejlepsi = min(znamky)
nejhorsi = max(znamky)

print("Nejlepší známka: " + str(nejlepsi))
print("Nejhorší známka: " + str(nejhorsi))

# Bonus - průměr:
soucet = sum(znamky)
prumer = soucet / len(znamky)
print("Průměr: " + str(prumer))
